# wasm-opt-binaries

Prebuilt `wasm-opt` from the etcimon/binaryen `svelte-d` fork.
`bunx svelte-d setup` downloads `wasm-opt-<triple>.tar.gz` from this branch.

- wasm-opt-darwin-x86_64.tar.gz
- wasm-opt-linux-aarch64.tar.gz
- wasm-opt-linux-x86_64.tar.gz
- wasm-opt-darwin-arm64.tar.gz
- wasm-opt-windows-x86_64.tar.gz
